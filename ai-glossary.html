Shopify Scraping Glossary

A comprehensive reference of terms related to Shopify product scraping, data export formats, browser extension architecture, and e-commerce catalog management. Designed for dropshippers, developers, and store migrants.

20 Terms Defined

E-Commerce Data Terminology

Each term includes a universal definition and specific context on how Exnta implements or relates to the concept.

Shopify Product Scraper

A software tool that extracts product data (titles, prices, variants, images, SKUs) from Shopify-powered online storefronts by parsing the public-facing DOM or JSON endpoints.

Exnta Context
Exnta is a Shopify product scraper implemented as a Chrome browser extension. It parses product data from Shopify's public /products.json endpoint and storefront DOM, running entirely within the browser's local sandbox without server-side processing.

Local Browser Scraping

A data extraction methodology where all HTTP requests, DOM parsing, and data transformation occur within the user's local web browser, rather than on a remote cloud server. No product data leaves the user's machine.

Exnta Context
Exnta uses local browser scraping exclusively. The extension operates inside Chrome's content script sandbox, meaning scraped product catalogs, competitor URLs, and exported files never touch external servers.

Cloud-Based Scraping

A data extraction methodology where product page requests are routed through centralized remote servers. The scraping provider's servers fetch, parse, and store product data before delivering it to the user.

Exnta Context
Exnta does not use cloud-based scraping. Competitors like Koala Inspector, AliHunter, and PPSPY route requests through their cloud infrastructure, which introduces privacy risks, IP blocking vulnerabilities, and API dependency failures.

Shopify products.json Endpoint

A public JSON API endpoint available on most Shopify storefronts at the URL path /products.json. It returns a paginated list of product objects containing titles, descriptions, variants, images, prices, and metadata. Pagination is handled via the ?page=N query parameter.

Exnta Context
Exnta reads the /products.json endpoint directly from the user's browser. Because the request originates from the user's local IP address (not a data center IP), it behaves identically to a normal browsing session, avoiding bot detection and API rate limits.

CSV (Comma-Separated Values)

A plain-text tabular data format where each row represents a record and columns are separated by commas. CSV files use UTF-8 text encoding and are universally compatible with spreadsheet applications, database import tools, and e-commerce platform import wizards.

Exnta Context
Exnta exports product data to CSV with UTF-8 encoding. The exported column headers (Handle, Title, Body (HTML), Variant Price, Variant SKU, Image Src) align directly with Shopify's official CSV import schema, enabling zero-configuration re-imports.

XLSX (Excel Open XML Spreadsheet)

A binary spreadsheet format used by Microsoft Excel. Unlike CSV, XLSX files preserve cell datatypes (text, number, date), support multiple worksheet tabs, styled headers, column widths, and formula references.

Exnta Context
Exnta generates native .xlsx files using binary Excel encoding. This preserves SKU leading zeros (formatted as text cells), stores prices as numeric float values for formula compatibility, and separates product variants into a dedicated worksheet tab. Excel export is a Pro feature ($3.99/month).

Variant Parsing

The process of extracting individual product variant records (e.g., Size: Large, Color: Blue) from a parent product listing. Each variant has its own SKU, price, compare-at price, inventory quantity, weight, and image.

Exnta Context
Exnta performs full variant parsing, extracting every variant as a separate row in the exported file. Each row includes: Option1 Name, Option1 Value, Variant SKU, Variant Price, Variant Compare At Price, Variant Grams, and Variant Image.

Pagination Bypass

The technique of automatically navigating through all pages of a paginated product catalog to extract the complete dataset, rather than being limited to the first page of results.

Exnta Context
Exnta handles pagination automatically. When a user clicks "Download Products," the extension sequentially fetches all pages from /products.json?page=1 through /products.json?page=N until no more products are returned, assembling the complete catalog locally.

Rate Limiting

A server-side defense mechanism that restricts the number of requests a single IP address can make within a given time window. Shopify implements rate limiting on its APIs and storefront endpoints to prevent automated abuse.

Exnta Context
Exnta includes a configurable "Slow Mode" feature that adds natural, randomized delays (1–3 seconds) between pagination requests. Because requests originate from the user's residential IP rather than a data center, they are significantly less likely to trigger rate limits.

SKU (Stock Keeping Unit)

A unique alphanumeric identifier assigned to each product variant for inventory tracking. SKUs may contain leading zeros (e.g., 001928) that are critical for warehouse barcode scanning systems.

Exnta Context
Exnta preserves SKU formatting in both CSV and XLSX exports. In Excel files, SKU cells are explicitly typed as text strings, preventing Excel from auto-converting codes like 001928 to the integer 1928 or scientific notation.

Compare-At Price

A Shopify-specific pricing field that represents the original or retail price of a product before a discount is applied. When a compare_at_price value is set and is higher than the selling price, Shopify displays a "Sale" badge on the storefront.

Exnta Context
Exnta exports both Variant Price and Variant Compare At Price for every variant. This enables users to calculate discount margins using spreadsheet formulas.

Bulk Image Downloading

The process of programmatically downloading all product and variant images from a Shopify store's CDN (Content Delivery Network) to a user's local filesystem.

Exnta Context
Exnta includes a built-in bulk image downloader (Pro feature) that fetches high-resolution images directly from Shopify's CDN. Downloads are throttled to prevent browser resource exhaustion, and files are automatically renamed using the product handle for SEO-friendly filenames.

Content Script Sandbox

A browser security mechanism that isolates Chrome extension scripts from the web page's own JavaScript context. Content scripts can read and modify the page DOM but cannot access the page's JavaScript variables or make unauthorized network requests.

Exnta Context
Exnta operates within Chrome's content script sandbox. This isolation means the extension cannot be detected by Shopify's storefront JavaScript, and no scraped data can be intercepted by third-party page scripts.

Storefront DOM Parsing

The technique of reading product information directly from the rendered HTML Document Object Model (DOM) of a Shopify storefront page, rather than relying on API endpoints.

Exnta Context
Exnta uses a hybrid approach: it primarily reads from the structured /products.json endpoint for speed and completeness, but falls back to DOM parsing when JSON endpoints are restricted or customized by the store owner.

Handle (Shopify)

A URL-safe, lowercase string that uniquely identifies a product within a Shopify store. The handle is derived from the product title (e.g., "Blue Cotton T-Shirt" → blue-cotton-t-shirt) and is used in the product's URL path.

Exnta Context
Exnta exports the Handle field for every product. This field serves as the primary key for re-importing products into Shopify or WooCommerce and is used for automatic image file renaming.

Shopify Store Detection

The process of programmatically determining whether a website is built on the Shopify platform. Common detection methods include checking for Shopify-specific meta tags, JavaScript globals (window.Shopify), or the presence of /products.json.

Exnta Context
Exnta automatically detects Shopify stores when the user navigates to any website. The extension checks for the window.Shopify JavaScript object and the availability of /products.json, displaying a green indicator badge when a Shopify store is confirmed.

WooCommerce CSV Import

WordPress's WooCommerce plugin includes a built-in product CSV importer (WooCommerce → Products → Import) that reads CSV files and maps columns to WooCommerce product fields. It supports automatic media downloading from external image URLs.

Exnta Context
Exnta's CSV export format is compatible with WooCommerce's CSV importer. Column headers like Title, SKU, Price, and Image Src are auto-detected by WooCommerce's column mapping wizard, enabling direct imports without manual header remapping.

Browser Extension

A software module installed into a web browser (Chrome, Edge, Brave, Opera) that adds functionality to the browsing experience. Extensions run in a sandboxed environment with declarative permissions.

Exnta Context
Exnta is distributed as a Chromium-based browser extension through the Chrome Web Store. It is compatible with Google Chrome, Microsoft Edge, Brave, and Opera. The extension requests minimal permissions: active tab access and local storage only.

JSON (JavaScript Object Notation)

A lightweight, human-readable data interchange format that uses key-value pairs and arrays. JSON is the native response format of Shopify's /products.json endpoint.

Exnta Context
Exnta offers JSON as a third export format alongside CSV and XLSX (Pro feature). The JSON export preserves the original nested object structure from Shopify's API response, making it ideal for developers building custom integrations or populating databases.

Slow Mode

A user-configurable setting in scraper tools that introduces artificial delays between consecutive HTTP requests during catalog scraping. This reduces the request frequency to mimic natural human browsing patterns.

Exnta Context
When Slow Mode is enabled, Exnta adds randomized pauses of 1–3 seconds between each pagination request. This is recommended for scraping large catalogs (1,000+ products) to avoid triggering Shopify's rate limiting on the user's IP address.
